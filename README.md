# 🛡️ AI Log Sentinel

AI-powered cybersecurity log analysis system that detects and responds to threats in real-time using Machine Learning and Gemini AI.

---

## 🚀 Features

- 🔍 Log parsing & threat detection
- 🤖 AI-powered attack analysis (Gemini)
- 🧠 ML anomaly detection (Isolation Forest)
- 🚫 Auto IP blocking system
- 📧 Email alert system
- 📊 Dashboard with charts & attack visualization
- 🌍 IP geolocation tracking

---

## 🧠 AI Capabilities

- Detects attack type (SQL Injection, Brute Force, etc.)
- Assigns severity (Low / Medium / High)
- Suggests action (Monitor / Block)
- Provides explanation with confidence score

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- Scikit-learn
- Google Gemini AI
- Git & GitHub
